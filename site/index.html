WHAT WISENSEHUB DOES

Two steps: schema, then task preprocess

Native files stay intact. Fixed-size model views are derived and audited.

01 · Schema

Standardize structure

Convert heterogeneous releases into one NPZ + JSON contract with explicit axes, masks, labels, and provenance.

[T, S, Tx, Rx]+metadata.json+valid_mask
02 · Task view

Preprocess per task profile

Resample, crop, or pad time so clips for the same task share rate, duration, and layout—without inventing absolute calibration.

profile Hz·duration / T·layout
